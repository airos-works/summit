# Interop 2025 and 2026 follow-up on Haiku

On November 19, we used the patched x86-64 Haiku build to rerun all 317 URLs that had failed or produced inconclusive results in the November 17 release review. **141 passed on rerun**. The other 176 produced assertion failures, image mismatches or inconclusive results. The 4,235 URLs with a clean November 17 observation were outside this targeted rerun. The 70 crash fixtures remain untested. [Release review and original focus-area tables](https://github.com/airos-works/summit/issues/243)

## Reproducing the review

Use the [Summit Interop runner](../tools/interop2026/README.md) with WPT `ad65e3da226065fbc12c9fe4f61bea408f5bbf1d` and wpt-metadata `e436f29035ed820de89fc2cbfbd9f80d49d220a0`. Generate the combined list with `--year 2025 --year 2026`. To repeat this targeted run, select the URLs whose November 19 outcome in the CSV differs from `omitted` and pass the resulting list to `run.sh`.

Testing used software-rendered air/OS QEMU guests running the Haiku Summit package with incrementally rebuilt engine components. The 201 assertion and inconclusive files ran with engine changes through `81b1719` and the viewport change in `557aa6b`. The inline-anchor and 116 image reruns also included `e1840ba`. WebDriver set the CSS viewport to 800 × 600 for the latter runs. The table baseline and grid shorthand runs each compared otherwise identical Haiku engines built from the `694a82b` release sources. The original release review selected the best completed observation per URL. This follow-up uses the latest observation within its targeted runs.
